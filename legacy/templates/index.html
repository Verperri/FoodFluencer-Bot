Setup — Get your free Google API key

  1. Go to console.cloud.google.com and create (or select) a project.
  2. Enable these APIs: Places API and Maps JavaScript API.
  3. Go to APIs & Services → Credentials → Create API key.
  4. Copy the key and paste it into your .env file: 
    GOOGLE_API_KEY=your_key_here
  5. Restart the server (python app.py) — done!
