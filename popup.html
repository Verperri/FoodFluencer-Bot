Google Places API Key

The API key unlocks automatic business discovery and the 4th image source. You can skip and add it later in Settings.

📋 How to get a free key:

  1. Go to console.cloud.google.com
  2. Create a project → Enable Places API (New)
  3. Go to Credentials → Create an API key
